홍진경 유튜브 2026.04.03 맞춤법 특강

왜 맞춤법을 지켜야 할까?

맞춤법은 서로를 배려하는 '약속'이다

💡 핵심 메시지

"말"이라는 것은 약속이다. 네모난 판을 '칠판'이라고 부르기로 정한 것처럼, 맞춤법도 "이럴 때는 이렇게 쓰자"는 사회적 약속이다.

줄임말(예: 버카충 = 버스카드 충전)은 같은 세대끼리만 통하지만, 맞춤법은 모든 세대가 소통하기 위한 공통 규칙이다. 약속을 지키지 않으면 누군가는 못 알아듣는다.

이금희 아나운서의 접근법: K-POP 가사 속에 숨어 있는 맞춤법 오류를 찾아보며, 재미있게 맞춤법을 익히자!

Rule 1

되 vs 돼 구분법

🎵
관련 가사 예시
"말도 안 되잖아 / 말도 안 돼잖아" — 어떤 게 맞을까?
🔑 핵심 공식
'하'가 들어가면 → 되
'해'가 들어가면 → 돼

'되'와 '돼'를 헷갈릴 때는, 그 자리에 '하'와 '해'를 각각 넣어본다. '하'가 자연스러우면 '되'가 맞고, '해'가 자연스러우면 '돼'가 맞다.

✅ 올바른 적용

"말도 안 돼잖아" → "말도 안 해잖아" ✓ (자연스럽다)

"안 돼요" → "안 해요" ✓

❌ 틀린 예시

"말도 안 되잖아" → "말도 안 하잖아" ✗ (어색하다)

기억법: '돼' = '되+어'의 줄임말. 받침이 'ㅚ'(되)인 곳에 모음 어미가 붙으면 '돼'가 된다. 짝대기(ㅣ) 하나 차이로 의미가 달라진다!

Rule 2

헷갈리다 vs 헛갈리다

🎵
가사 속 예시
"나를 엇갈리게 했어" — 헷갈리다? 헛갈리다?
헷갈리다 ⭕ 표준어
헛갈리다 ⭕ 표준어

둘 다 맞다! '헷갈리다'와 '헛갈리다'는 복수 표준어로 인정된다.

📌 복수 표준어란?

원래 표준어가 아니었던 말이 너무 많이 쓰여서 표준어로 추가 인정된 것. '짜장면'이 대표적인 예다.

원래 '자장면'만 맞았지만, 사람들이 '짜장면'을 너무 많이 써서 둘 다 표준어가 되었다. 말은 사람들이 많이 다니다 보면 길이 만들어지듯 자연스럽게 변화한다.

Rule 3

설렘 vs 설레임

🎵
가사 속 예시
"설레임의 밤잠 설치게 했던 그 말" vs "설렘의…"
설렘 ⭕ 올바른 표현
설레임 ❌ 아이스크림 이름일 뿐

왜 '설렘'이 맞을까?

설레다 + ㅁ(명사형 접미사) = 설렘

'설레다'에 명사를 만드는 'ㅁ'을 붙이면 '설렘'이 된다. '설레임'은 아이스크림 상표명일 뿐, 올바른 한국어가 아니다.

비슷한 예: 미움(미워+ㅁ), 기쁨(기쁘+ㅁ), 슬픔(슬프+ㅁ)

예술적 허용: 시, 노래, 그림 등 예술 작품에서는 맞춤법을 약간 틀리는 것이 허용된다. 이것이 예술의 묘미이지만, 일상에서는 '설렘'으로 쓰는 것이 올바르다.

Rule 4

-든 vs -던 구분법

🎵
IZ*ONE — Wanna Be 등
"살든 말든" / "이럴 거면 그러지 말걸 그날"
🔑 핵심 구분
-든 = 선택 (런던의 'ㄴ' 빼기)
-던 = 과거·회상 (런던 = 역사의 도시)

📖 -든: 선택형

"선택"할 때 사용한다. 반드시 둘 이상의 선택지와 함께 나온다.

예: 살든 말든 / 이것이든 저것이든 / 하든 말든

📖 -던: 과거·회상

"과거"를 떠올릴 때 사용한다. '런던(London)'이 역사와 전통의 도시인 것처럼 과거형이다.

예: 그러지 말걸 그날 / 좋아하던 사람 / 할 듯 말 듯 내밀던

✅ 정리

"살든 말든" → 선택 (사는 것 OR 마는 것)

"좋아하던 노래" → 과거 회상 (예전에 좋아했던)

Rule 5

어떡해 vs 어떻게

🎵
레드벨벳 — Psycho / 청하 — 어떻게 벌써
"어떡해 / 어떻게"의 차이
🔑 핵심 구분
어떻게 = 부사 (뒤에 뭔가 더 와야 함)
어떡해 = 독립형 ("어떻게 해"의 줄임)

📖 어떻게 (부사)

부사는 혼자서 문장을 완성하지 못한다. 반드시 뒤에 꾸며줄 말이 와야 한다.

예: "어떻게 할까?" / "어떻게 해서 늘어났을까?"

📖 어떡해 (독립 표현)

"어떻게 해"의 줄임말로, 혼자서도 완전한 의미를 가진다.

예: "이 일을 어떡해!" / "나 어떡해?"

✅ 구분 테스트

뒤에 말이 더 이어지면 → 어떻게 (부사)

그 자체로 끝나면 → 어떡해 (독립)

Rule 6

-대 vs -데 구분법

문자, 톡에서 90% 이상이 틀리는 대표적 맞춤법 오류라고 이금희 아나운서는 강조한다.

🔑 핵심 구분
-대 = 전달 (남이 말한 것을 전해줄 때)
-데 = 직접 경험 (내가 직접 보거나 느꼈을 때)

📖 -대 (전달)

다른 사람이 한 말을 전달할 때 사용한다.

예: "지선이가 봤는데 재미있대" → 지선이가 재미있다고 해(-다고 하다 → -대)

📖 -데 (직접 경험)

내가 직접 경험한 것을 말할 때 사용한다.

예: "내가 봤는데 재미있데" → 내가 직접 보니까 재미있더라(-더라 → -데)

-대 전달 (남의 말)
"~다고 해"의 줄임
-데 직접 경험 (나의 경험)
"~더라"의 줄임
실전 예시:
• "그 영화 재미있대" = 누군가가 재미있다고 말해줌 (전달)
• "그 영화 재미있데" = 내가 직접 봤더니 재미있었음 (경험)

Bonus

"눈이 높던데" — 복합 활용

"눈이 높던데"처럼 -던(과거 회상)과 -데(직접 경험)가 결합하는 경우도 있다.

✅ 분석

"눈이 높던데" = 내가 직접 봤는데(-데), 과거에 그랬다(-던)

→ "내가 보니까 눈이 높더라" (직접 경험의 과거 회상)
