Overview

핵심 메시지 한 줄

"좋은 칩 하나보다 좋은 메모리 계층, 좋은 스케일업 패브릭, 좋은 엑스퍼트 스케줄링이 더 중요한 시대가 왔다."

NVIDIA가 GTC 2026에서 발표한 Rubin 아키텍처의 진짜 혁신은 단순히 LPU(언어 처리 유닛) 추가가 아니다. 추론(Inference) 시스템 전체를 메모리 계층별로 분해해 각 병목을 다른 하드웨어로 처리하는 구조로 전환한 것이다.

페타플롭스·코어 수 같은 컴퓨팅 지표보다, 데이터를 어디에 저장하고 어떤 경로로 얼마나 자주 옮기느냐가 실제 추론 성능을 결정한다.

Key Technology

MoE: 연산은 줄이고
통신은 늘리는 구조

MoE(Mixture of Experts)는 모델을 여러 "전문가(Expert)" 모듈로 나누고, 각 토큰이 추론 시 일부 전문가만 활성화하는 아키텍처다. 전체 파라미터를 키우면서도 토큰당 활성 파라미터를 제한해 효율을 높인다.

핵심 트레이드오프
연산량 ↓ / 통신 병목 ↑

필요한 전문가만 켠다 → 연산량 감소. 그러나 어떤 토큰이 어느 전문가로 갈지 라우팅해야 하므로, GPU 간 All-to-All 통신이 필수. 이 통신 자체가 새로운 병목이 된다.

Memory Deep Dive

KV 캐시: 점점 커지는
장기 기억

KV 캐시(Key-Value Cache)는 트랜스포머가 이전 토큰들의 키·밸류를 저장해 재계산을 피하는 구조다. 모델의 "기억"에 해당한다.

에이전트 AI, 멀티턴 대화, 긴 문서 처리가 일반화될수록 KV 캐시 크기가 모델 파라미터보다 더 빠르게 증가한다. 이를 SRAM이나 HBM에만 담을 수 없다.

"모델은 요만한데 KV 캐시가 엄청나게 늘어난 경우도 많아요. 그래서 CMX라고 하는 거를 내세운 이유가 바로 이겁니다."
1
Hot KV Cache → SRAM / HBM4 현재 활성 컨텍스트. 초고속 접근 필요.
↓ 오래될수록
2
Warm KV Cache → LPDDR / GDDR7 최근 히스토리. 중간 속도로 충분.
↓
3
Cold KV Cache → CMX (NAND Flash) 장기 배경 지식·에이전트 히스토리.
느리지만 대용량. 최대 5배 향상된 전력 효율.

Semiconductor Basics

왜 SRAM은 빠르고 비싼가?

SRAM은 로직 반도체(CPU·GPU와 동일한 공정)와 같은 웨이퍼 위에 제작된다. 칩 내부에 붙어 있어 접근 지연이 극히 짧다.

SRAM 셀이 트랜지스터 6개를 사용하기 때문에 면적 효율이 나쁘다. 웨이퍼 면적을 많이 차지할수록 수율이 하락하고 칩 단가가 상승한다. 따라서 SRAM은 용량을 무한정 늘릴 수 없다.

Implications

AI 추론 시대의
3가지 핵심 시사점

①
컴퓨팅→메모리 패러다임 전환 추론 시대엔 FLOPS가 아닌 메모리 계층 설계가 실제 성능을 결정한다. 데이터 이동 경로와 읽기 빈도가 핵심 지표다.
②
MoE는 연산 효율과 통신 비용의 교환 전체 파라미터 확장과 토큰당 연산 절감이라는 이점 뒤에, Expert 라우팅 통신 오버헤드라는 비용이 숨어 있다. NVLink급 패브릭이 필수다.
③
하나의 메모리 타입이 승자가 될 수 없다 SRAM·HBM·GDDR·LPDDR·NAND 각각이 특정 용도에서 최적이다. 단일 메모리의 극단적 주장(HBM 종말·DRAM 대체 등)은 맥락을 무시한 단순화다.
