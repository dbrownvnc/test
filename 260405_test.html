AI 발전 단계와
에이전틱 AI의 등장

인공지능은 세 단계를 거쳐 진화해 왔습니다. 각 단계는 컴퓨팅 자원의 수요를 크게 바꾸었으며, 현재의 에이전틱 AI 단계가 메모리 폭발적 수요 증가의 핵심 원인입니다.

  • 1
    판별형 AI (Discriminative AI)
    알파고 등 결정·판단 특화. 사진을 보고 강아지/호랑이를 구분하는 수준. GPU 계산 경쟁이 핵심이었던 시대.
  • 2
    생성형 AI (Generative AI)
    ~2024년. 글 쓰고, 그림 그리고, 음악 작곡, 동영상 생성. ChatGPT, Gemini 등이 대표 주자. GPU 성능 경쟁이 지배했던 시기.
  • 3
    에이전틱 AI (Agentic AI) 현재
    2024년 말부터. 알아서 심부름까지 완료하는 자율 AI. 개인화·지속 학습·수수료 생태계 구축이 목표. 메모리가 새로운 경쟁력의 핵심.
AI 단계별 핵심 경쟁력 변화
성능을 결정하는 주요 자원의 중요도 비교
🔑 에이전틱 AI의 3대 특성

① 초개인화(Hyper-Personalization) — 개인의 모든 데이터를 학습해 나보다 나를 더 잘 아는 AI
② 평생 지속 학습 — 추론(Inference) 과정에서 실시간으로 추가 학습
③ 수익 생태계 — 광고·수수료·사용료 구조로 플랫폼이 돈을 버는 시스템 구축

"알고리즘의 차이는 거의 없어졌어요. 성능의 차이가 어디서 왔냐면 작년까진 GPU에서 왔어요. 근데 지금은 초개인화된 에이전틱 AI가 되면 누가 데이터를 많이 갖고 있느냐가 결정합니다."
Part 2

컨텍스트 엔지니어링이란?

프롬프트 엔지니어링은 말(텍스트)로만 AI에게 지시하는 방식이었다면, 컨텍스트 엔지니어링은 파일, 문서, 이미지, 동영상, 웹사이트까지 첨부해서 더 정확한 의도를 전달하는 방식입니다.

💬
프롬프트 엔지니어링
텍스트 질문만으로 AI에게 지시. "맥킨지 스타일 PPT 만들어줘" → 정확도 낮음
📎
컨텍스트 엔지니어링
파일 첨부 + 웹사이트 지정 + 과거 문서 참조. → 정확도 대폭 향상

왜 메모리 수요를 폭발시키는가?

컨텍스트 엔지니어링으로 AI에 입력되는 토큰(Token) 수가 급격히 증가합니다. 기존 텍스트 기반 수천~수만 개에서, 이미지·동영상·대용량 문서가 포함되면 100만 개(1M 토큰) 이상으로 늘어납니다.

컨텍스트 길이의 폭발적 성장
AI 세대별 처리 가능한 최대 토큰 수 (로그 스케일)
📚 컨텍스트 엔지니어링 = 오픈북 시험

과거에는 외워서 시험(프리트레이닝 후 추론 분리). 지금은 책을 보면서 시험(추론 중 실시간 학습). AI가 참조할 모든 자료를 메모리에 올려두고 실시간으로 읽으면서 답변 → 메모리 용량 = AI 성능

김정호 교수가 강조하는 핵심 4요소:

  • 1
    메모리(기억장치) — 개인의 과거 대화·문서·위치 등 모든 기록 보관
  • 2
    소프트웨어 도구 — 엑셀, PPT, 이메일, 유튜브 등 외부 앱 접근
  • 3
    외부 인터넷 검색 — 최신 데이터 실시간 반영
  • 4
    프롬프트 — 이제 가장 작은 동그라미(4가지 중 기본)
Part 3

단기 vs 장기 메모리:
HBM·HBF vs NAND Flash

AI의 메모리는 인간의 기억처럼 단기 메모리와 장기 메모리로 나눌 수 있습니다. 각각을 담당하는 반도체 종류가 다르며, 양쪽 모두 수요가 폭발적으로 늘어납니다.

구분 단기 메모리 장기 메모리
역할 실시간 행렬 계산, KV 캐시 저장, 빠른 추론 개인 전체 기록, 과거 대화, 의료 기록 등 장기 보관
비유 의사 책상 서랍 안 차트 (자주 오는 환자) 창고 보관 차트 (3년 만에 온 환자)
반도체 HBM (High Bandwidth Memory), HBF NAND Flash (샌디스크, 마이크론, 삼성)
특징 GPU 옆에 바짝 붙어, 초고속·대용량 멀리 있어도 OK, 대신 광통신으로 빠르게 연결
주가 상승 기업 SK하이닉스, 삼성전자, 마이크론 웨스턴디지털(샌디스크), 마이크론
💡 ICMS = 새 키워드

Inference Context Memory Storage — 엔비디아가 추진하는 아키텍처. GPU 옆 HBM/HBF 대신, 멀리 있는 대용량 NAND Flash를 광통신으로 연결해 쓰겠다는 전략. 랜드 플래시 수요가 급증하는 이유.

메모리 계층별 특성 비교
속도(대역폭)와 용량의 트레이드오프
Part 4 · 공식 1

KV 캐시 메모리 용량 공식

트랜스포머(Transformer) AI 모델에서는 단어와 단어 사이의 관계를 KV 캐시(Key-Value Cache)라는 행렬로 저장합니다. 이 크기를 결정하는 공식이 메모리 수요의 핵심입니다.

공식 1 — KV Cache Memory Size
MKV = S × B × P × H × 2 × L × D
S = Sequence Length (컨텍스트 길이, 현재 128K → 미래 1M+)
B = Batch Size (동시 사용자 수, 10만 명이면 10만 배)
P = Precision (소수점 정밀도, 16bit or 32bit)
H = Number of Heads (AI가 처리하는 '과목' 수)
2 = K(Key) 행렬 + V(Value) 행렬
L = Number of Layers (딥러닝 깊이, 층 수)
D = Head Dimension (각 토큰을 몇 차원 벡터로 표현하냐)

왜 이 공식이 무서운가?

모든 변수가 곱하기로 연결되어 있습니다. 덧셈이 아닌 곱셈이기 때문에, 변수 하나가 10배가 되면 전체가 10배, 변수 세 개가 10배씩 늘면 1,000배가 됩니다.

🧮 곱하기의 공포

S가 현재 128K에서 1M으로 늘면 약 8배. 동시 사용자가 10만 명이면 10만 배. 컨텍스트에 동영상이 들어가면 텍스트 대비 수십~수백 배. 이 모든 변수가 동시에 곱해지면 메모리 수요는 이론적으로 수만~수십만 배까지 증가할 수 있습니다.

KV 캐시란 무엇인가?

트랜스포머 모델에서 '어텐션(Attention)'이란 단어들 사이의 관계를 점수로 매기는 과정입니다. 이때 각 단어의 Key(어떤 정보인가)와 Value(그 정보의 내용)를 행렬로 저장한 것이 KV 캐시입니다.

단어 100개면 100×100 행렬이지만, 컨텍스트 엔지니어링으로 100만 개가 되면 1,000,000×1,000,000 행렬이 필요해 메모리가 기하급수적으로 늘어납니다.

Part 5 · 공식 2·3

밴드위스와 스루풋

메모리 용량이 충분해도, 얼마나 빠르게 읽어올 수 있느냐(밴드위스)가 사용자 체감 성능을 결정합니다.

레이턴시 vs 스루풋

⏱
레이턴시 (Latency)
AI에게 질문하고 첫 번째 단어가 나오기까지의 시간. GPU의 계산 능력에 의해 결정됨.
⚡
스루풋 (Throughput)
첫 단어 이후 1초에 몇 개의 단어(토큰)를 쏟아내느냐. 메모리 밴드위스가 결정함.
공식 2 — 밴드위스 (Bandwidth, BW)
BW = Speedper line × Nlines × Nlayers
Speed/line = 라인당 전송 속도 (Gbps, 구리 한계 ~100Gbps)
N_lines = 데이터 라인 수 (HBM3: 1024 → HBM4: 2048)
N_layers = 다층 버스 구조 (한 번에 여러 층으로 전송)
공식 3 — 토큰 생성 시간 (Time per Output Token)
Ttoken = Tcompute + Data Size / BW
T_compute = KV캐시 계산에 필요한 GPU 연산 시간 (레이턴시)
Data Size / BW = KV캐시·컨텍스트 전체 데이터를 메모리 밴드위스로 나눈 값
→ 두 번째 항이 압도적으로 지배 = 메모리 밴드위스가 속도를 결정
🚌 버스 비유로 이해하기

밴드위스 = 고속도로 차선 수 × 제한 속도
• 라인 수 늘리기 = 차선 추가 (HBM3→HBM4: 1024→2048)
• 라인당 속도 높이기 = 제한속도 상향 (엔비디아 NVLink, 브로드컴 기술)
• 다층 버스 = 1층이 아니라 10층 고속도로로 한번에 많이 보내기

HBM 세대별 밴드위스 향상
데이터 라인 수 기준 상대 성능 비교

왜 AI가 처음에 "생각하는 척" 하나?

ChatGPT 등을 쓸 때 처음에 "thinking..." 이 길게 나오는 것은 GPU가 KV캐시를 만드는 시간(레이턴시)입니다. 한번 첫 단어가 나오면 이후에는 쭉쭉 빠르게 나오는데, 이것이 메모리 밴드위스(스루풋)가 결정합니다.

GPU의 한계와 메모리로의 전환

과거에는 GPU 성능 경쟁이었다면, 이제는 GPU 성능을 높이는 유일한 방법이 메모리 용량 2배 + 밴드위스 2배입니다. GPU 자체는 발열이 심하고 성능 향상 여지가 적어, 게임의 주도권이 GPU에서 메모리로 넘어왔습니다.

핵심 결론 및 산업적 시사점

AI 성능 결정 요소의 무게 중심 이동
시대별 가장 중요한 경쟁 요소 (교수 관점 기준)

교수의 3대 핵심 주장

  • 1
    AI 성능은 메모리에서 온다 — 알고리즘 차이는 거의 없어졌고, 데이터(메모리)가 경쟁력을 결정한다
  • 2
    KV 캐시 공식의 곱셈이 메모리 수요를 폭발시킨다 — 컨텍스트 엔지니어링 시대에 1,000배~수만 배 이상의 메모리가 필요
  • 3
    병목은 두 가지: 용량 + 밴드위스 — 둘 다 해결해야 진짜 AI 성능이 올라간다

산업적 시사점

분야내용관련 기업
HBM 단기 메모리 수요 폭발. 고용량·고대역폭 필수 SK하이닉스, 삼성, 마이크론
NAND Flash 장기 메모리 수요 급증. ICMS 아키텍처 핵심 샌디스크, 마이크론, 삼성
광통신 멀리 있는 메모리를 빠르게 연결하는 수단 브로드컴, 각 광통신 업체
메모리 공장 완공까지 3년, 기술 축적 필요. 선점 경쟁 중 일론 머스크(xAI Tera Fab), 빅테크
GPU 업체 메모리 없으면 GPU 성능도 의미 없음 엔비디아(NVLink), AMD
"저게 맞다면 지금이라도 현대차가 자동차 만들 일 아니고, 삼양이 라면 만들 때가 아니라, 다 모여서 지금 메모리 만들어야 되네요."
⚠️ 교수가 경고하는 시나리오

현재 삼성·하이닉스·마이크론의 생산량은 수요에 한참 못 미칠 가능성이 높음. 메모리 공장을 짓더라도 3년 이상 소요. 이 공백 기간이 AI 성능 경쟁과 가격 결정의 핵심 변수가 될 것. 비용과 전기요금을 누가 감당하느냐에 따라 AI 사업의 성패가 갈릴 수 있음.

미래 사회 변화 예측

교수는 개인 메모리의 크기가 사회적 계층을 나눌 것이라고 예측합니다. 구독료를 많이 낼수록 더 많은 메모리를 할당받아 더 정확하고 빠른 AI 서비스를 받고, 무료 사용자는 2일치 기억만 유지하는 방식으로 차별화될 수 있습니다. "메모리 몇 테라바이트짜리 사람이야?"가 미래의 경제력 척도가 될 수 있다는 것입니다.
